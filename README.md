# JeremiahPark.dev

Personal portfolio of Jeremiah Park, built with Vite + React and deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text, links, photos, and project info live in `src/data.js`.
Images and the resume PDF are in `public/`.

## Deploy

Every push to `main` builds and deploys automatically via GitHub Actions
(`.github/workflows/deploy.yml`) to https://bakhoon.github.io
